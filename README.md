
# 🌱 Smart Agri

An IoT-based smart agriculture system that combines real-time environmental monitoring, weather forecasting, and intelligent irrigation recommendations.

## 🎯 Project Overview

Smart Agri aims to help users monitor soil conditions and make better irrigation decisions using IoT devices, weather data, and an Android application.

## ✨ Planned Features

- Real-time soil moisture monitoring.
- Temperature and humidity monitoring.
- Weather forecasting integration.
- Intelligent irrigation recommendations.
- AI-powered agricultural assistant.
- Android monitoring dashboard.
- Irrigation alerts and notifications.
- Water pump control.

## 🛠️ Proposed Tech Stack

| Component | Technology |
|---|---|
| Mobile Application | Kotlin, Jetpack Compose |
| Hardware | ESP32, Sensors |
| IoT Simulation | Wokwi |
| Database | Firebase Realtime Database |
| Weather API | Open-Meteo |
| API Integration | Retrofit |
| AI Agent | To be determined |
| Version Control | Git & GitHub |

## 🌿 Development Workflow

- `main` — Stable project version.
- `feature/android` — Android development.
- `feature/hardware` — IoT and hardware.
- `feature/ai-agent` — AI assistant.
- `feature/weather` — Weather API integration.
- `feature/docs-testing` — Documentation and testing.

Team members should work on their assigned branches and submit pull requests for review before merging into `main`.

## 🔒 Security Guidelines

- Never commit passwords or private API keys.
- Never commit Firebase service account credentials.
- Keep Wi-Fi credentials and sensitive configuration files out of the repository.
- Review changes before merging.
